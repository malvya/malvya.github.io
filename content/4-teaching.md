This file is your Teaching page.

HOW TO EDIT
Each course is ONE line, in this shape:

    CODE | Course title | When you taught it

Underneath any course you may add ONE optional line:

    Description: what the course is about.

Fill it in and the text appears inside that course's card. Leave it blank, or
delete the line entirely, and the card just shows the code, title and term.
You can describe some courses and not others.

To add a course, add a line in the right group.
To remove one, delete its line (and its Description line, if it has one).
To add a whole new group, copy a "## Group" block.

When you are done, open Claude Code in this folder and type:  /update-website
