# 5 — Publications

This file is your Publications page.

HOW TO EDIT
Each publication is a small block. Only "Title:" is required — delete any line
you do not need, or leave it blank.

    Title:   the name of the piece
    Where:   the journal, book or organisation it appeared in
    With:    co-authors, if any
    Link:    a web address, if there is one

TO ADD A PUBLICATION: copy any block, paste it under the right year, and edit.
If the year is not there yet, write a new "Year:" line above your entry.

Entries appear in the order you list them here.
When you are done, open Claude Code in this folder and type:  /update-website
